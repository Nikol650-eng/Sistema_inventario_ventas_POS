## Cómo ejecutar el proyecto en 3 pasos

### Paso 1. Clonar el repositorio.

Abre una terminal y ejecuta:

```bash
git clone https://github.com/Nikol650-eng/Sistema_inventario_ventas_POS.git
```

### Paso 2. Entrar a la carpeta del proyecto.

```bash
cd Sistema_inventario_ventas_POS
```

### Paso 3. Ejecutar el programa.

Asegúrate de tener Python 3 instalado y ejecuta:

```bash
python main.py
```

El sistema abrirá la interfaz gráfica del punto de venta de la veterinaria. La base de datos SQLite se utiliza para almacenar la información del sistema.

Si el comando `python` no funciona en Windows, prueba con:

```bash
py main.py
```
